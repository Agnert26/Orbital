# 🛰️ ORBITAL — Beyond the Mission

A premium futuristic space mission design game created for the **NASA Space Apps Challenge 2026**.

## 🌟 Project Overview

**ORBITAL - Beyond the Mission** is an interactive web-based space simulator that puts you in command of humanity's most advanced space exploration program. Choose from multiple mission types, manage resources, and make critical decisions that will shape the future of space exploration.

## 🚀 Challenge Category

**Space Mission Design Game**

## ✨ Features

### Current Implementation (v1.0)

- **Mission Selection System**: Choose from three unique space missions:
  - 🔴 **Mars Exploration**: Pioneer the Red Planet
  - 🌍 **Earth Observation**: Monitor our home planet
  - ☄️ **Asteroid Research**: Study near-Earth asteroids

- **Resource Management Dashboard**: Track and manage critical resources:
  - Budget allocation
  - Energy reserves
  - Crew personnel
  - Equipment status

- **Premium UI/UX Design**:
  - Futuristic glassmorphism interface
  - Neon cyan and electric blue color scheme
  - Smooth animations and transitions
  - Responsive design (desktop and mobile)
  - Animated starfield background

- **Interactive Elements**:
  - Clickable mission cards with selection feedback
  - Dynamic mission overview panel
  - Functional navigation sidebar
  - Real-time resource tracking
  - Start mission functionality

## 🎮 How to Play

### Getting Started

1. **Select Your Mission**:
   - Review the three available missions
   - Click on a mission card to view detailed information
   - Check the mission requirements and objectives

2. **Review Resources**:
   - Monitor your available budget
   - Check energy and crew availability
   - Ensure equipment is ready

3. **Start Mission**:
   - Once you've selected a mission, click the "Start Mission" button
   - Confirm your decision in the dialog
   - Resources will be automatically allocated

### Mission Types

#### 🔴 Mars Exploration
- **Duration**: 687 days
- **Difficulty**: High
- **Budget**: $2.5B
- **Objectives**: Land safely, deploy equipment, collect samples, establish communications

#### 🌍 Earth Observation
- **Duration**: 365 days
- **Difficulty**: Medium
- **Budget**: $1.2B
- **Objectives**: Launch satellites, monitor climate, track deforestation, provide early warning

#### ☄️ Asteroid Research
- **Duration**: 540 days
- **Difficulty**: Extreme
- **Budget**: $1.8B
- **Objectives**: Rendezvous with asteroid, deploy mining equipment, analyze composition, test deflection

## 🔧 Installation & Setup

### Local Development

1. **Clone or download the repository**

2. **Navigate to the project directory**:
   ```bash
   cd orbital-mission-game
   ```

3. **Open in browser**:
   - Simply open `index.html` in your web browser
   - Or use a local server (recommended):

   **Using Python**:
   ```bash
   # Python 3
   python -m http.server 8000
   ```

   **Using Node.js**:
   ```bash
   # Install http-server globally
   npm install -g http-server
   
   # Run server
   http-server
   ```

   **Using VS Code**:
   - Install "Live Server" extension
   - Right-click on `index.html`
   - Select "Open with Live Server"

4. **Access the game**:
   - Open your browser and navigate to `http://localhost:8000` (or the port shown)

### GitHub Pages Deployment

1. **Push to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: ORBITAL mission game"
   git branch -M main
   git remote add origin <your-repo-url>
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to repository Settings
   - Navigate to "Pages" section
   - Select "main" branch as source
   - Click "Save"

3. **Access your deployed game**:
   - Your game will be available at: `https://yourusername.github.io/repository-name/`
